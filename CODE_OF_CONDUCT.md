# Code of Conduct

LoRA Pilot is intended to be a welcoming, practical, and technically serious project. Participation in issues, discussions, pull requests, documentation, code review, and community spaces is covered by this code.

## Expected behavior

- Be respectful and constructive, including during disagreement.
- Focus criticism on code, behavior, documentation, or decisions rather than people.
- Use clear, inclusive language and assume good faith while checking the evidence.
- Accept useful feedback without personalizing it.
- Protect other people's privacy, credentials, private infrastructure details, and generated content.
- Give maintainers and contributors room to correct mistakes.

## Unacceptable behavior

- Harassment, intimidation, discrimination, or unwanted sexual attention.
- Personal attacks, insults, threats, trolling, or deliberately inflammatory behavior.
- Publishing private information, credentials, tokens, or private conversations without permission.
- Spam, bad-faith disruption, impersonation, or intentionally misleading reports.
- Sharing malicious code, payloads, or instructions outside an appropriate private security report.

## Scope and enforcement

This code applies in project repositories, issue trackers, pull requests, discussions, documentation, and any public or private space where someone is representing LoRA Pilot.

Project maintainers may edit, reject, close, or remove contributions that violate this code and may restrict participation when necessary to protect the community. Responses should be proportionate, consistent, and focused on restoring a safe and useful project space.

Report conduct concerns privately to the project maintainers through the repository owner or another private project contact. Do not include secrets or unnecessary personal information in the report. Reports will be handled as confidentially as practical.
