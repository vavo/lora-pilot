Off by default: existing ComfyUI URLs and API clients keep working without credentials. When enabled, browsers use your ControlPilot login and external API clients need a token.

Set a ControlPilot password first. Applying a change restarts ComfyUI and interrupts running generations. Protected access uses the URL below; unauthenticated requests to the direct ComfyUI port are blocked, including through a provider proxy.

Tokens only grant ComfyUI access. Replacing or revoking a token invalidates the previous token. Removing it does not disable protection; browser login continues to work.

Choose storage carefully

Shutdown uses RunPod API v2. Provide RUNPOD_API_KEY on the backend or use the injected RunPod CLI credential. Stop keeps the pod available to restart. Remove deletes the pod and its local storage. Keep anything you need on a network volume or in a backup.
