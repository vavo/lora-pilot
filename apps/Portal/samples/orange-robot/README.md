# Meet the orange robot

These are the eight original 1024-pixel SDXL images used in the LoRA Pilot video recording on 1 October 2026. They are sample inputs generated with ComfyUI and SDXL base 1.0, not results from a trained LoRA. The images are unchanged. Their captions have been reviewed against the visible content and use the original trigger word, `pilotceramic`.

The robots vary in shape and detail. This small dataset teaches an orange robot concept and the training workflow; it is not a validated dataset for reproducing one exact mascot. Review the captions in Caption images, train a Quick test, and compare the saved checkpoints against the base model before deciding what to keep.

The generated demo assets and captions are distributed with LoRA Pilot under the repository's MIT license. Model weights are not included. The manifest records file hashes, provenance, a starting profile and a comparison prompt. Training quality and hardware performance require an actual GPU run; the package does not claim benchmark results.
